
# GlowNest Facebook Ads Campaign

## Facebook Ads Campaign Capstone Project

This project is a practice Facebook Ads campaign created for GlowNest, a skincare website. The main purpose of this project was to understand how a Facebook Ads campaign is planned, created, targeted and optimized.

## About GlowNest

GlowNest is a skincare-focused website created to showcase skincare products and provide users with information about different skincare options.

Website: https://glownestskincare.unaux.com

## Campaign Objective

The main objective of the campaign was to increase website traffic and introduce GlowNest to potential customers.

The campaign was designed as a practice campaign and was not intended to run with real advertising expenditure.

## Target Audience

The campaign audience was planned according to the skincare category.

- Location: India
- Age Group: 18–35 years
- Gender: Women
- Interests: Skincare, Beauty, Cosmetics, Self-care and Personal Care

## Budget and Bidding

A practice budget was selected while setting up the campaign in Meta Ads Manager.

The campaign was created for learning and demonstration purposes. No real advertising expenditure or campaign performance data was used in this project.

## Ad Format

The campaign used a visual ad creative designed to attract the attention of people interested in skincare.

The creative included:

- Product-focused visual
- Primary ad text
- Headline
- Description
- Call-to-action
- Music/creative enhancements where applicable

## Campaign Strategy

The campaign strategy focused on reaching people who are interested in skincare and beauty products.

The main approach was:

1. Select a relevant campaign objective.
2. Define a suitable target audience.
3. Create an attractive skincare-focused ad.
4. Select suitable placements.
5. Direct interested users towards the GlowNest website.
6. Review campaign metrics and make improvements if the campaign were to be run live.

## Campaign Setup

The campaign was created using Meta Ads Manager.

The setup included:

- Campaign objective
- Budget settings
- Audience targeting
- Placements
- Ad creative
- Primary text
- Headline
- Description
- Call-to-action
- Final ad preview

Screenshots of the campaign setup and ad are included in this repository.

## Analytics and Reporting

Since this was a practice campaign and was not run as a live paid campaign, actual performance results were not available.

If the campaign were run live, the following metrics would be monitored:

- Reach
- Impressions
- Click-through rate (CTR)
- Cost per click (CPC)
- Landing page views
- Engagement
- Results/Conversions

These metrics would help determine how well the campaign was performing and where improvements could be made.

## Optimization Plan

If the campaign were run live, optimization would include:

- Testing different ad creatives
- Testing different headlines and primary text
- Comparing audience groups
- Monitoring CTR and CPC
- Adjusting placements based on performance
- Increasing or reducing budget according to results

## Challenges Faced

During the project, some challenges were faced while working with Meta Ads Manager, including understanding campaign settings, audience targeting, placements and creating suitable ad creatives.

Another challenge was setting up the campaign as a practice project without actually running a paid campaign.

## Key Learnings

This project helped me understand the basic process of creating a Facebook Ads campaign.

I learned about:

- Meta Ads campaign structure
- Campaign objectives
- Audience targeting
- Budget and bidding
- Ad placements
- Ad creative creation
- Campaign optimization
- Important advertising metrics

## Future Recommendations

For a future live campaign, multiple ad creatives and audience groups could be tested to identify which combinations perform better.

The campaign could also be optimized using real performance data such as CTR, CPC, engagement and conversions.
